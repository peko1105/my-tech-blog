## 一、博客工作原理

你的博客是一个**静态网站**，不需要服务器和数据库，工作流程如下：

```
你在 VS Code 写 Markdown 文章
        ↓
    git push 推送到 GitHub
        ↓
  GitHub Actions 自动构建
        ↓
  部署到 GitHub Pages（全球可访问）
```

## 二、写一篇新文章

### 在 VS Code 终端中执行：

```bash
cd C:/Users/win10/my-tech-blog

# 创建文章
hexo new post "我的第一篇文章"
```

这会在 `source/_posts/` 下生成 `我的第一篇文章.md`。

### 编辑文章：

打开生成的 `.md` 文件，顶部是文章属性（叫 **Front Matter**），下面是正文：

```markdown
---
title: 我的第一篇文章          # ← 文章标题
date: 2026-07-09 17:00:00     # ← 日期
tags:                          # ← 标签（可以有多个）
  - STM32
  - 嵌入式
categories:                    # ← 分类
  - 嵌入式
description: 文章简介          # ← 描述（可选）
cover: /img/default-bg.svg     # ← 封面图（可选）
---

## 第一章

这里是正文，使用 Markdown 语法编写...
```

### 常用 Markdown 语法：

| 效果 | 写法 |
|------|------|
| **粗体** | `**粗体**` |
| `代码` | `` `代码` `` |
| 代码块 | ```` ```c 代码内容 ``` ```` |
| 图片 | `![描述](图片路径)` |
| 链接 | `[文字](网址)` |
| 表格 | 见下方示例 |

### Markdown 写表格：

```markdown
| 外设 | 用途 | 难度 |
|------|------|------|
| GPIO | 控制LED | ⭐ |
| UART | 串口通信 | ⭐⭐ |
| I2C | 传感器通信 | ⭐⭐⭐ |
```

## 四、插入图片

### 方法一：本地图片（推荐）

1. 把图片放到 `source/img/` 目录
2. 文章中引用：

```markdown
![电路图](/img/circuit.png)
```

### 方法二：开启文章资源文件夹

在 `_config.yml` 中已有 `post_asset_folder: true`，创建文章时会同时生成一个同名文件夹，把图片放进去即可：

```markdown
![电路图](电路图.png)
```

## 五、本地预览

发布前在本地确认效果：

```bash
cd C:/Users/win10/my-tech-blog
hexo server
```

浏览器打开 **http://localhost:4000** 即可预览。修改文章后刷新浏览器就能看到变化。

按 `Ctrl+C` 停止预览。

## 六、发布上线

确认文章没问题后，推送到 GitHub：

```bash
cd C:/Users/win10/my-tech-blog
git add -A
git commit -m "新文章: 我的第一篇文章"
git push
```

推送后约 **1 分钟**，网站自动更新。去 https://peko1105.github.io/my-tech-blog/ 就能看到新文章。

## 七、修改网站设置

所有配置文件都在项目根目录：

| 文件 | 控制什么 |
|------|---------|
| `_config.yml` | 网站标题、URL、作者名等 |
| `_config.butterfly.yml` | 主题外观、导航菜单、社交链接、评论等 |

修改后同样 `git commit` + `git push` 即可生效。

### 常见修改示例：

```yaml
# _config.yml — 改网站标题
title: 我的嵌入式博客

# _config.butterfly.yml — 改社交链接
social:
  fab fa-github: https://github.com/peko1105 || GitHub
  fab fa-bilibili: https://space.bilibili.com/你的ID || B站
```

## 八、删除文章

```bash
# 删除文章文件
rm source/_posts/要删除的文章.md

# 提交删除
git add -A
git commit -m "删除文章"
git push
```

## 九、目录结构速查

```
my-tech-blog/
├── _config.yml              # ← 网站主配置
├── _config.butterfly.yml    # ← 主题配置
├── source/
│   ├── _posts/              # ← 文章放这里！
│   │   └── 我的文章.md
│   ├── img/                 # ← 图片资源
│   ├── css/custom.css       # ← 自定义样式
│   ├── about/index.md       # ← 关于页面
│   └── link/index.md        # ← 友链页面
├── scaffolds/               # ← 文章模板
└── .github/workflows/       # ← 自动部署配置
```
