## 一、背景说明

本博客使用以下技术栈：

- **Hexo**：静态博客框架（Node.js 环境）
- **Butterfly**：博客主题
- **GitHub Pages**：托管和部署
- **SSH 密钥**：用于向 GitHub 推送代码的身份验证

重装系统后，C 盘所有文件都会被清除，因此以下内容会丢失：

| 会丢失 | 不会丢（在 GitHub 上） |
|--------|----------------------|
| Node.js 环境 | ✅ 所有博客源代码 |
| Git 环境 | ✅ 所有文章 |
| Hexo CLI | ✅ 所有配置 |
| SSH 密钥 | ✅ GitHub Actions 部署配置 |
| `my-tech-blog` 文件夹 | ✅ 网站历史版本 |

---

## 二、重装前的备份（强烈建议做）

### 2.1 备份 SSH 密钥

将以下文件复制到 U 盘、移动硬盘或网盘：

```
C:\Users\你的用户名\.ssh\github_peko      ← 私钥文件（没有后缀名）
C:\Users\你的用户名\.ssh\github_peko.pub  ← 公钥文件
C:\Users\你的用户名\.ssh\config           ← SSH 配置文件
```

> 整个 `.ssh` 文件夹一起复制最省事。

**如果你忘了备份**，也不要紧。跟着下面第三章操作，重新生成一个新密钥，在 GitHub 上替换一下就行，只是多花两分钟。

### 2.2 如果博客不在 C 盘

如果你的博客文件夹不在 C 盘（比如在 D 盘 `D:\my-tech-blog`），重装系统不影响它，直接跳到第四章。

### 2.3 备份 C 盘的博客文件夹（如果博客在 C 盘）

```
C:\Users\你的用户名\my-tech-blog\
```

整个文件夹复制到其他盘或网盘。

## 三、重装系统后的恢复步骤

### 第一步：安装 Node.js

1. 打开浏览器访问：**https://nodejs.org**
2. 下载 **LTS（长期支持版）**，通常是左边那个绿色的按钮
3. 双击安装，一路点"下一步"，全部用默认选项即可
4. 安装完成后验证：

打开 **命令提示符** 或 **PowerShell**，输入：

```bash
node -v
```

应该看到版本号，比如 `v20.x.x`。

```bash
npm -v
```

也应该看到版本号，比如 `v10.x.x`。

### 第二步：安装 Git

1. 打开浏览器访问：**https://git-scm.com**
2. 点击 Download，下载 Windows 版本
3. 双击安装，全部用默认选项，一路点"下一步"
4. 安装完成后验证：

```bash
git --version
```

应该看到 `git version 2.x.x`。

> 💡 如果下载速度慢，可以用国内镜像：[npm.taobao.org/mirrors/git-for-windows/](https://npm.taobao.org/mirrors/git-for-windows/)

### 第三步：安装 Hexo 命令行工具

打开命令提示符或 PowerShell，输入：

```bash
npm install -g hexo-cli
```

安装完成后验证：

```bash
hexo version
```

应该看到 Hexo 版本号及相关信息。

### 第四步：设置 Git 用户信息

```bash
git config --global user.name "peko"
git config --global user.email "peko1105@163.com"
```

> ⚠️ **邮箱必须和 GitHub 账号绑定的邮箱一致**，否则提交记录不会关联到你的 GitHub 头像。

### 第五步：恢复 SSH 密钥

**情况 A：你备份了密钥**

把之前备份的 `.ssh` 文件夹整个复制到：`C:\Users\你的用户名\.ssh\`

**情况 B：没备份，需要重新生成**

打开命令提示符，输入：

```bash
ssh-keygen -t ed25519 -C "peko1105@163.com" -f ~/.ssh/github_peko
```

> 提示输入密码时直接按回车（不设密码），共按两次。

查看生成的公钥：

```bash
cat ~/.ssh/github_peko.pub
```

复制输出的一整段文字（以 `ssh-ed25519` 开头）。

然后创建 SSH 配置文件（重要！用于绕过国内 GitHub 访问问题）：

```bash
cat >> ~/.ssh/config << 'EOF'
Host github.com
  Hostname ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/github_peko
EOF
```

接着去 GitHub 添加公钥：

1. 打开浏览器访问：**https://github.com/settings/ssh/new**
2. Title 填 `my-blog-pc`（随便填，便于辨认）
3. Key 粘贴刚才复制的公钥
4. 点击 **Add SSH Key**

添加完成后验证：

```bash
ssh -T git@github.com
```

看到 `Hi peko1105! You've successfully authenticated...` 就说明成功了。

### 第六步：克隆博客代码到本地

如果之前把博客备份到了其他地方，可以直接复制回来，跳到第七步。

如果没有备份，从 GitHub 下载：

```bash
cd C:/Users/你的用户名
git clone git@github.com:peko1105/my-tech-blog.git
```

### 第七步：安装依赖包

```bash
cd C:/Users/你的用户名/my-tech-blog
npm install
```

这一步会下载 Hexo 和 Butterfly 主题需要的所有依赖包。网络慢的话耐心等待，通常 1-2 分钟。

### 第八步：验证恢复成功

```bash
hexo server
```

浏览器打开 **http://localhost:4000** ，如果能看到博客首页，说明恢复成功！

按 `Ctrl+C` 可以停止服务器。

## 四、常见问题

### Q1：`hexo server` 报错怎么办？

```bash
# 先清理缓存再试
hexo clean
hexo server
```

### Q2：`npm install` 下载很慢？

使用国内淘宝镜像：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q3：`git push` 提示 Permission denied？

说明 SSH 密钥没配置好，回到第三章第五步重新设置。

### Q4：`ssh -T git@github.com` 连接超时？

GitHub 在国内有时不稳定。检查 `~/.ssh/config` 文件是否正确配置了 `Port 443` 和 `ssh.github.com`。参考第三章第五步。

### Q5：忘记 GitHub 账号密码？

用绑定的邮箱 `peko1105@163.com` 在 GitHub 登录页面点击"Forgot password"找回。

### Q6：博客文件夹还在但 `git push` 不工作？

确认当前目录是博客文件夹，检查远程仓库地址：

```bash
cd C:/Users/你的用户名/my-tech-blog
git remote -v
```

应该显示 `git@github.com:peko1105/my-tech-blog.git`。

如果不是，重新设置：

```bash
git remote set-url origin git@github.com:peko1105/my-tech-blog.git
```

## 五、恢复完成检查清单

恢复完成后，逐项确认：

- [ ] `node -v` 显示版本号
- [ ] `git --version` 显示版本号
- [ ] `hexo version` 显示版本号
- [ ] `ssh -T git@github.com` 显示 `Hi peko1105!`
- [ ] `hexo server` 能正常启动
- [ ] http://localhost:4000 能看到博客首页
- [ ] `git pull` 能从 GitHub 拉取最新代码

全部打勾 ✅ 后，就可以继续写文章了！
